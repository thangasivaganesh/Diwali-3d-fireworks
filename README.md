# 🎆 3D Diwali Fireworks & Realistic Interactive Crackers

A complete, cinematic 3D Diwali celebration experience built with **React**, **Vite**, **Three.js**, and **Tailwind CSS**. Features procedural 3D Indian Diwali crackers, full-sky 3D fireworks, sacred interactive Diyas & Rangoli, synthesized Web Audio sound effects, and bilingual English + Tamil support.

---

## ✨ Features

### 1. 🪔 Realistic 3D Indian Crackers
- **Anar (Fountain)**: Conical flower pot with procedural Indian motif canvas wrapper and gold foil bands. On ignition, shoots a vertical fountain of shimmering gold sparks, glowing embers, and fading smoke.
- **Phuljhari (Sparkler)**: Slender metallic wire with chemical coating and glowing tip. **Interactive**: drag your mouse or touch across the screen to wave the sparkler in 3D space!
- **Rocket**: Aerodynamic multi-stage rocket with colorful nose cone, fins, and stick. Launches into the upper sky with an exhaust fire trail and explodes into a spherical burst.
- **Chakri (Ground Wheel)**: Circular disc with metallic spiral patterns that spins violently on the ground, emitting rotating rings of golden and crimson sparks.
- **Sutli Bomb (Visual Simulation)**: Twine-wrapped cylindrical model with fuse countdown spark, bright flash, and colorful particle burst.
- **Golden Cascade (Waterfall)**: Suspended hanging tubes showering a curtain of glittering golden willow particles.

### 2. 🌌 Full 3D Night Sky Fireworks
- Click or tap anywhere in the sky to launch a rocket directly toward that location.
- Multi-burst variations: Chrysanthemum, Peony, Willow, Ring, Heart, Starburst, and Rainbow bursts.
- Physics simulation with gravity, velocity drag, additive blending, and natural particle fading.

### 3. 🪔 Sacred 3D Diyas & Rangoli Mandala
- Traditional terracotta clay lamps with flickering emissive flames and dynamic point lights.
- Click individual diyas in 3D to light them, or use "Light All Diyas" to illuminate the sacred Rangoli mandala floor.

### 4. 🌐 Bilingual Support (English + தமிழ்)
- Seamless top-right language switcher (🇬🇧 English / 🇮🇳 தமிழ்).
- Complete natural translations for all headlines, descriptions, buttons, tooltips, and cracker specs.
- Language preference saved in `localStorage`.

### 5. 🔊 Procedural Web Audio API Sound Effects
- Rocket launch whistles, deep explosion booms, fountain hissing, chakri spinning whir, sparkler crackles, and temple chimes.
- Starts **muted** by default; enabled with a single click.

### 6. ⚙️ Floating Glassmorphism Control Panel
- Launch single firework, trigger **Mega Explosion**, or **Grand Finale**.
- Auto Fireworks show toggle.
- Rainbow / Golden color palette modes.
- Particle intensity & show frequency sliders.
- Fullscreen mode, clear sky, and personalized wishes editor.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation & Run

1. Open PowerShell or Terminal and navigate to the project directory:
   ```bash
   cd d:\Diwali-3d-fireworks
   ```

2. Install dependencies (already installed):
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open your browser to the URL displayed (usually **http://localhost:5173**).

4. To create an optimized production build:
   ```bash
   npm run build
   ```

5. To preview the production build locally:
   ```bash
   npm run preview
   ```
